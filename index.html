What gets calculated

Nucleotide sequences

  • Base composition, GC content and a sliding-window GC profile
  • GC skew, molecular weight, melting temperature
  • Open reading frames across all six frames
  • Restriction sites for 16 common enzymes
  • Three-frame translation, reverse complement, codon usage

Protein sequences

  • Molecular weight and theoretical isoelectric point
  • GRAVY score and Kyte-Doolittle hydropathy profile
  • Net charge at pH 7 and molar extinction coefficient
  • Amino acid composition and aromaticity

Need primers, alignment, microsatellites or a virtual digest? Those live in the tab.

Toolkit

Four analyses that go beyond basic characterization. Primer design, microsatellite detection and restriction digestion use the sequence loaded in the Analyzer; pairwise alignment takes two sequences of its own.

Constraints

Melting temperatures use nearest-neighbour thermodynamics (SantaLucia 1998), which is more accurate for primers than the GC formula used elsewhere in this app.

Candidates are also filtered for a 3′ GC clamp, homopolymer runs over 4, and self-complementarity.

Two sequences

Needleman-Wunsch global alignment. Protein sequences are scored with BLOSUM62 and detected automatically. FASTA or raw sequence both work.

Simple sequence repeats

Finds microsatellites using the MISA thresholds (Thiel et al. 2003): mononucleotide repeats need 12 or more copies, dinucleotide 6, trinucleotide and tetranucleotide 5, penta and hexanucleotide 4. SSRs are the basis of most molecular marker development.

Virtual restriction digest

Select enzymes to cut with and see the resulting fragments on a simulated gel. Cut positions account for where within the recognition site each enzyme cuts.

    About this project

    What it does

    GeneCharacterize brings the whole of a genome-wide gene family characterization into one place: routine sequence calculations, the ordered checklist of web services a full study requires, and a notebook to record what each step returned. The protocol and the analysis engine apply equally to plant and animal genomes.

    It does not replace the specialist tools. Alignment, phylogeny, domain assignment, motif discovery, localization and structure prediction are handed off to the same established, peer-reviewed services the field already cites, so results remain exactly as authentic as running each tool by hand. What changes is that nothing gets skipped, nothing has to be re-pasted, and the parameters you used are recorded as you go.

    The analysis engine implements standard methods from scratch in JavaScript — GC content, melting temperature, six-frame ORF detection, isoelectric point by bisection on the Henderson-Hasselbalch charge curve, Kyte-Doolittle hydropathy, nearest-neighbour primer thermodynamics, Needleman-Wunsch alignment, and MISA-threshold microsatellite detection.

    Analysis happens entirely in the browser. Your sequence is transmitted only when you explicitly click through to an external service.

    Methods and limitations

    • Melting temperature in the Analyzer uses the Wallace rule below 14 nt and the salt-adjusted GC formula above it. The Toolkit's primer designer uses nearest-neighbour thermodynamics, which is more accurate.
    • Isoelectric point is found by bisection on the Henderson-Hasselbalch charge curve using a selectable pKa set (Bjellqvist/ProtParam by default, plus EMBOSS, Lehninger, Solomon and Thurlkill). Published values differ by up to 0.5 pH units depending on which set the authors' software used, so always state the set you report.
    • ORF detection requires a canonical ATG start and does not account for introns, alternative starts or non-standard genetic codes.
    • Primer design screens Tm, GC, GC clamp, homopolymers and self-complementarity, but does not check specificity against a genome. Always BLAST your primers.
    • Alignment uses linear gap penalties, not affine. For publication-quality alignment use MAFFT or EMBOSS Needle.
    • Restriction analysis covers 16 common enzymes and ignores methylation sensitivity and star activity.
    • Predictions from linked external tools are predictions, not evidence.

    Built with

    Vanilla JavaScript with no framework, Chart.js for visualization, and a test suite run with the Node.js built-in test runner. The computation modules (js/seqlib.js, js/seqtools.js, js/notebook.js) are written as pure functions with no DOM dependencies, which is what makes them testable — 274 unit tests validate the calculations against published reference values such as the molecular weight of glycine (75.07 Da), the Kyte-Doolittle index of isoleucine (4.5), and the BLOSUM62 self-score of tryptophan (11).
